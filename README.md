# Sentinel Studio

Atoma demonstration: Executive Brief, My Decisions, Reports and Ask Pulse.

Demo sign-in: sunil.demo / AtomaDemo2026!

All data is synthetic. The sign-in is a presentation feature, not real security. Campaign actions are session-only simulations. No live models, data or operator systems are connected.

## Publish
Extract this archive. On GitHub, open subinkrishnan/Sentinel-Studio, choose Add file > Upload files, then drag the extracted files and the assets and vendor folders onto the page. Upload the contents, not an enclosing folder. Ensure index.html is at the repository root. Include .nojekyll if your computer displays hidden files. Commit changes.

Open repository Settings > Pages. Select Deploy from a branch, main, /(root), and Save. Wait for the Pages deployment to complete; GitHub will display the published URL.

## Local preview
Run python3 -m http.server 8000 from this folder and open http://localhost:8000.

SheetJS Community Edition 0.20.3 is vendored. Its Apache 2.0 licence is in vendor/SHEETJS-LICENSE.txt.
